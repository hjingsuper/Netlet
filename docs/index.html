安装指南

三步安装，
即刻开始。

Netlet 暂无 Apple Developer ID 证书，因此首次打开需要在系统设置中手动允许。这是免费开源项目当前的分发方式，不影响软件在本机运行。

  1. 01

    下载 DMG

    下载适用于 Apple Silicon 的 Netlet v1.4。

  2. 02

    拖入“应用程序”

    打开 DMG，将 Netlet 拖到“应用程序”文件夹。

  3. 03

    允许首次打开

    若被系统阻止，在“隐私与安全性”中点击“仍要打开”。

系统要求

macOS 14 或更高版本，Apple Silicon（M1 或更新芯片）。

Local first

你的流量，
只属于你的 Mac。

Netlet 只读取 macOS 提供的网络接口累计字节数，并在本机计算速度。它不检查网络内容，不需要账户，也不收集或上传任何数据。

只有在你检查软件更新时，应用才会连接 GitHub Releases。

Open source

免费、开放，
保持专注。

源代码公开于 GitHub。没有广告、订阅或隐藏服务，只有一个清楚可靠的菜单栏网速工具。
